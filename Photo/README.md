# Фото моделей

Назва файла відповідає моделі: `HP EliteBook 850 G7.jpg`, `HP Zbook g4.jpeg`.
Підтримуються JPG, JPEG, PNG, WebP, AVIF. Фото — спільне для карток цієї моделі.

Після додавання або перейменування файлів виконай із кореня проєкту:

```sh
npm --prefix other run photos
```

Завантаж на хостинг папку `Photo` разом з оновленим `index.json`.
Каталог перевіряє індекс при завантаженні та автоматичному оновленні.

Зіставлення не залежить від регістру. Точна модель має пріоритет.
Для короткої назви `HP EliteBook G7` використовується єдине доступне фото
цього сімейства й покоління. Якщо є кілька варіантів, уточни назву моделі
в каталозі. Для явно вказаної `840 G7` фото `850 G7` не підставляється.
Якщо фото немає або воно не завантажилось, залишається ілюстрація.
Кнопка «Фото» й фільтр фото, як і раніше, стосуються фотографій у Telegram.
